# HLA-Tok-C 实现与冻结口径

## 输入与准入

实验基于 V3 的 `b3b3366`，使用 Seed 1 C0 第 10,000 步和同一批 174 帧 DAVIS2017 Validation。数据由原 `AuditedFrames` 逐帧验证文件摘要。仅静态排序校准可以读取 Train。V3 原始报告、历史权重与数据清单只读引用。

原 V3 评估器首先重放最大预算，三项指标均需通过冻结容差。后续矩阵沿用 LPIPS-Alex、DISTS 和 RGB MSE 实现，使用同一组感知权重。DISTS 每个当前源帧预计算一次原生参考特征，距离归约继续调用上游实现。与 Phase 0 的 K16320 RGB MSE、逐帧 PSNR、LPIPS-Alex 和 DISTS 逐值核对。Global PSNR 从所有原生有效 RGB 元素的 MSE 计算。

V3 八档中有三档超出 K16320，采用任务给定的八档备用预算。任意整数 K∈[1,16320] 可解析。校验的 50 个新预算由冻结种子对合法整数集合无放回抽样，边界另外登记。V3 的连续部分用原邻档容差及可复用的增益门槛，最大预算用 C0 复现容差。

## 固定模型与排序

`encode_continuous` 复用 R2 现有查询块及 rank-major 连续路径。发送时一次编码 K16320，排序后截断。静态重排保存原 Rank、实际区域和查询向量。接收端只含 Local Decoder 与 RGB Decoder，按实际收到的 Rank 集合和原始位置做恢复。

O0 保持原顺序。O1 反转 121 个实际 Rank，保留 Rank 内的区域顺序和最后一个原始 Rank 的 120 个区域。O2 对冻结种子选定的 12 个 Train 来源各取一帧，用逐 Rank 删除的平均 RGB MSE 增量降序排序，分数相同时按原 Rank 升序。排序表在 O1/O2 首次 Validation 评价前发布。

保留最大预算质量的候选在 K510、K1020 或 K2040 至少有一档达到表中一项实质改进阈值，并且同档其余指标在预先冻结的劣化容差以内，即进入码流评估。主排序取这三档平均 Global PSNR 最高的候选，顺序相同则取名称排序靠前的候选。O0 保留为基线。

## 跨帧和动态预算

R2 对每帧单独建立局部查询 memory。发送端和接收端的跨帧历史均为空，FIXED 和 CLOSED 对完整 Validation 使用同一实际无状态评价。代表帧在各预算和排序的独立接收端重复解码核验逐位一致。连续片段的早期、中期、晚期差异用于观察片段内容变化和预算影响。

动态预算逐个视频运行六条独立序列。每帧实际输出与同一源帧、预算、排序、精度的独立解码逐位核对，再取相应的已测量质量。这里的状态只涉及同一帧增量接收及截止时间。收到后续帧时始终可以独立解码。
