# Training and data separation

The only fitting inputs are eight disjoint archived Train clips of 32 contiguous frames; Calibration holds out four other Train clips, also 32 frames each. The film identities and per-frame digests are revalidated from the archived manifest. The base loop runs native FP16 encoding and independent decoding at full resolution on the original contiguous videos. For enhancement fitting, aligned `256×256` crops of the already decoded reference and source are cached. Cropping does not create a new predictor boundary. No full-frame optimization or final full-resolution fine tuning is implied by these runs.

Anchor uses BF16 autocast, FP32 loss/rate terms, AdamW with `1e-4`, gradient accumulation, and finite gradient checks with clipping. The model optimizes a differentiable multirate residual objective and logs the surrogate rate separately from actual HUF1 byte ledgers. A1 uses 4-frame samples. A2 resumes from the admitted A1 checkpoint and uses 8-frame samples; the 2,000-step target is cumulative. Checkpoints record model, optimizer, scheduler, RNG, data cursor, pinned weight hashes, source identity and configuration every 500 updates. Validate checkpoints at full 1920×1080, batch 1, with real bytes.

The first 500-step attempt belongs to the rejected shared-scratch lineage and is not the admitted A1 checkpoint. `A2_admission.json` records the gated rerun and the checkpoint SHA-256. Do not use Validation for fitting or calibration, and do not read Test pixels before the final gate. The UF experiment CLIs intentionally expose no Test split.
