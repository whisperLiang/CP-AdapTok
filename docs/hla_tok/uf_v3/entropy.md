# 最终 Seed 2 静态整数 CDF

128 张 Train Calibration 原生帧用于拟合和预注册比较。保留每条记录的组、依赖层、排序和原生 Base。E0、E1 和 E2 分别从实际字节恢复相同整数画布，潜在和 D1 RGB 逐位一致。E1 表预装 7,296 B。标准 12 B 段头中的 CDF/index/模式字节、CRC、完整 payload 和每条 rANS 的 4 B 终止均进入账本。Raw fallback 在这批帧中命中 0 次。

| E0 支持 | E1 相同符号全包节省 | 相同符号仅增强节省 | 同上限 E0 / E1 LPIPS |
|---|---:|---:|---:|
| 5 Mbps | 4.67% | 5.05% | .26199 / .26064 |
| 10 Mbps | 7.10% | 7.38% | .24190 / .24064 |
| 20 Mbps | 10.31% | 10.51% | .22704 / .22523 |
| 40 Mbps | 16.23% | 16.42% | .21816 / .21801 |
| All valid | 16.87% | 17.06% | .21773 / .21773 |

V2 早期 41%–48% 是当时特定量化/概率配置在固定同符号支持上的完整应用层节省。最终 Seed 2 重测只达到上述比例。40 档下 E1 使用 27.4532 Mbps，较 E0 的 32.1547 Mbps 少约 4.70 Mbps。全记录时两者画质一致，下一步提升画质仍需提高传输表示的信息量。冻结的同预算保护与三轮时延通过，默认 E1。40 Mbps Full-max 为 33.96 FPS、P95 32.67 ms。E0 为 35.99 FPS、P95 30.69 ms。未启用二者之外的更多精度或 Detail。

V2 的 E0 端点按实际等感知码率排序。其最终 E1 对照使用了较早校准表与 Seed 1，40 档同等画质有所压缩，低档等感知结果落后。V3 的选择使用当前 Seed 2 符号重新拟合的表。
