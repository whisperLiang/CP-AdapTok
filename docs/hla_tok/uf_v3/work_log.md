# V3 工作记录

- 从本地 V2 提交创建独立 V3 worktree 和分支。初始化锁定的 DCVC Gitlink，并把 ABI 一致的 V2 原生扩展复制到 V3 构建目录。
- 逐行核对 V2 阶段日志。P1 中间节点保存重叠快照，按相同内容去重。用 AdamW 张量计数核对步数，用逐张量哈希核对实际更新。
- 审计单测先因模块缺失失败，补齐后通过。在 H100 用冻结 Train 计划重放 V2 三阶段和 CUDA 权重折叠。
- 实际回放 Calibration 和 Validation 的 C0–C3，写出逐帧质量、合法增强容量与配对差。第一次 Calibration 全窗诊断遇到 I 帧在 2 Mbps 超顶，加入明确的预算与下游失步状态。机制诊断使用四个冻结窗的前 12 帧。
- 在同一 Seed 2 量化与 Base 参数下跑 D0-Fast 的 174 帧三轮 Full-max。核对 Original AdapTok 的 1,044 个档位与源帧键、实际窗口字节及指标聚合。
- 从最终 V2 Seed 2 的 128 张 Calibration 帧重拟合 CDF。固定整数和组序，核对 E0/E1/E2 实际应用字节、D1 RGB 和 Full-max。按冻结规则选 E1。
- 复现原始 D0 与批量 D0-Fast 的 34 帧字节、整数边界和 RGB。V2 Final Seed 2 共享相同已调整的原生权重。
- 实测 L0 与预注册 L1。记录所有 I/P Base 的字节分布、可达帧、失步及完整 Base 诊断质量。L1 的最高 I 字节和感知质量均退化，留存失败资产。
- Seed 1 启动原始 RGB 训练。第一个两步检查点已完成更新，首次输出对 CUDA 和 CPU 张量直接做差而失败。在差值函数边界统一设备后，重跑两步并通过 checkpoint 续训至累计 500 步。失败副本保留在 V3 构建目录。
- P1 Calibration 的物理画质满足低档保护，但没有达到高档积极信号。首轮性能与主机另一项 GPU 工作重叠，保留原始结果并计划在实验独占时复核。P2 从已验证的 500 步 checkpoint 恢复。
- 用 CPU 的真实 I/P 骨干测试状态和分离率失真梯度。定向故障覆盖冻结 Encoder、移除率梯度、错误像素输入、重复 Encoder、旧 CUDA 参数及 CRC 合法的错误帧头。
- 从 500 步恢复至 2,000 步，Seed 1 阶段 P2 实测低档保护达标，高档实测提升小于预注册要求。短窗 I/P 延迟分项将 P95 超限定位到 I 帧频率及处理成本。
- 从 2,000 步 checkpoint 执行一次 64 步有限联合探针。首次展开原生 1080p I/P 连续 4 帧，验证率和失真均到达真实 Encoder，之后 63 次原生空间裁块更新。对每组选定张量记录有效梯度、绝对差、值域和哈希。
- 累计 2,064 步权重在第一次严格 Calibration 回放因 14,757 B Base 被拒绝。独立扫描 128 张发现两个 P 超限，峰值 19,403 B。I 帧峰值近乎未动。
- 重放同一原生联合首步，得到独立、可部署的累计 2,001 步 checkpoint。以原 9,212 B 门槛依次检查 128 帧 Calibration 与冻结 174 帧 Validation。通过后进入完整 RD、独立实时性、状态和同步验收。
- 通过 189 帧动态与 204 个固定预算验证独立 Base 状态，检测缺失 Base 后的拒绝与重同步，检查增量恢复与整包 RGB 逐位一致。原 CUDA 代理和未来像素注入都被实际捕获。
- 用最终 Seed 2 的 E1 做完整 174 帧 A2。A2 Full-max 四档达到工程门槛。保留 V3 超限与等感知回退。
- 对同一逐帧语义试了 C++ 打包工作区复用，用两种独立时钟记录 Full-max 和按需，并保留原始结果。只使用本地 V3 构建目录。
- 首轮 CUDA pytest 调用缺少权重环境变量，8 个原生用例被跳过。保留这一调用的账本后，按相同扩展和已校验权重重新执行。
- 工作区复用版对完整 174 帧分别做三轮 Full-max 和按需。逐帧最大包和全部合法边界与原构建哈希一致，独立重新验证参考、增量、断流及 FP16 权重。
- 使用选定构建重复 CPU 和 CUDA 回归。25 个源码定向变异均被捕获。额外记录旧 CUDA 代理与未来输入注入。
- 按冻结工程及 RD 门槛登记 A2 为最优研究对照，登记 A4 为实际联合训练候选。高率和等感知准入未达成，保持 Test 封存。
- 从真实逐帧、原生样例及计时日志生成 17 张图，检查多面板对齐、PDF 文字和对象遮挡。核对所有历史输入和研究产物的 SHA-256。
