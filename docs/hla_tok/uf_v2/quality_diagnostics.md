# 感知诊断

每个序列顺序解码前 12 帧，并在第 0、1、5、11 帧评分。12 帧来自三个冻结 Validation 序列。Q1–Q9 共享相同原生基础历史。用 YCbCr 通道替换观察亮度、色度归因，用原生 RGB 误差的 9×9 局部低通与残差查看空间频率。完整逐帧结果包含 RGB PSNR、LPIPS-Alex、DISTS 和各误差分量。

使用原图亮度替换时 LPIPS 约 0.047，替换色度约 0.419。替换高频误差约 0.084，替换低频误差约 0.334。两组反事实合起来支持在联合训练加入最小亮度高频项。替换结果使用原图信息，仅作为误差归因。

D0 从 5 Mbps 到最大合法前缀，LPIPS 在这 12 帧由约 0.476 降至 0.409。连续 latent 的反事实约 0.370，表明有效前缀截断和量化会损失一部分信息，Base 配置下原有 Encoder 表示也存在感知上限。该连续结果没有码率。全局固定扫描的 LPIPS 约 0.489，已部署残差排序约 0.476，带原始目标梯度的一阶离线 Oracle 约 0.470。Oracle 是局部排序对照，未用来传输或拟合。高码率官方 UF-LD 曲线提供独立平均码率对照。

原生图像与局部裁块来自相同坐标和统一 RGB 范围。PNG 校验清单记录来源帧和哈希。样例图只做 8-bit 量化及排版；裁块未缩放后作为模型输入。
