# UF-V2 工作日志

1. 从本地 A/B worktree 核验方案 B `3efe25e`、方案 A `a483a21` 和共同祖先 `502eaf6`。创建独立 V2 checkout，只读检查两份完整报告、机器表、源码、协议及 checkpoint。比对 Original 已封装 F13W 窗口账本与 174 帧实际字节。
2. 在同一 H100 和官方 FP16 扩展上运行 LD、Anchor、D0 性能采样。分别保存未插桩和插桩 wall time、Python/C++ 调用和 Kineto 可观察的传输。历史基线和正式吞吐范围来自各自完整 Validation 日志。
3. 在冻结的 174 帧上运行最低官方 QP 和 Base-Standard 固定 QP。完整解码保留探索性超限样本，主曲线按物理上限拒收。
4. 先用分组边缘、符号逃逸和真实前缀测试锁定 E0 wire，再把逐段 rANS 和分组换成可批处理的 CPU 路径。用独立收端逐字节、逐像素和基础 latent 对照历史运行时。
5. 保留官方 I 的头前重建 feature，P 的原生 reference feature 和当前帧 context 按值快照。两条 D1 分支共享原生重建头，零增强直接走 Base。记录首轮串行批处理的 40 Mbps 延迟失效，随后测量并行段打包和原生增量解析。
6. 对 Anchor-Fast 运行 `174×3` 原生帧每档 Full-max，并用留出的完整画质回放复核 A2 数值。保留 BF16 和 FP32 增强的计时拆分及独立按需模式。Base 圆整直接用物理 B 序列。
7. 用 Calibration 对实际 UF 两级整数统计静态 I/P CDF，计算同符号 E0/E1/E2 字节与重建整数。训练无 Test 读取。用 12 张 Validation 原生帧比较连续潜变量、两级量化、固定扫描、一阶 Oracle 以及亮度和频带替换。
8. 两个 D1 Pilot 从 500 步续训至 2,000 步。缓存来自同一帧一次最大码流和独立 Base 历史的四档真实解码输入。用完整 Validation 验证 D1 与静态迁移的质量和速度。在本地保存 checkpoint digest、实际优化器计数与每步损失。
9. 追踪 Crapper、Dryer、Mutator 与自定义故障注入。初次 CPU 回归暴露新 checkout 默认权重路径缺失，添加指向已校验权重的本地链接并重跑。两个定向故障最初被 CRC 和错误 payload 间接遮盖，改用合法异族包和合法缺依赖精化，重跑后都被捕获。
10. 500 步 D1 完成 99 帧和 90 帧连续动态带宽，每帧参考完全一致。两次遗漏 Base 均通过真正 I 帧恢复。静态 CDF 候选另运行包含低预算的链路验证。
11. 联合率失真继续使用原生官方时间状态。逐步启用有界 P 编码末层调整、原生 z 概率和共享读出增益，保留一次物理 Base 编码。每个续训节点从之前 checkpoint 加载并生成该节点的真实训练前缀，冻结采样顺序。首个 4,000 步节点达到四档实时性，完整码流中独立端 Base latent 一致。
12. 图表只读取本轮测量和已核验历史证据。每张 PDF 随渲染复查字体和碰撞，图像板从同一输入、标准 5 Mbps 前缀与统一原生坐标生成。
13. 完成 Seed 1 的 6,000 和 8,000 步有效联合节点及完整 Validation。静态 E1 复测三个周期，5/10 Mbps 均达到冻结质量，四档满足实时门槛。Seed 2 的 P1 静态率失真与 Seed 1 保持相近趋势。另追加带原生 Base-Only 的低预算动态回放。
14. 使用已归档 Original LPIPS 的完整十进制端点比较。历史 0.28978 是显示精度，精确 0.2897786209466814 与 1.394714 Mbps 为已测端点，无外推。25 dB 仍不在候选与历史 Original 的共同覆盖内，另报告直接观察的 2 Mbps 结果。
15. 根据 P2 完整真实码流的持续改善进入 P3。预注册两个连续节点无增益及严重高预算退化的停止规则，单次只训练并回放一个 2,000 步节点。原生参考、目录和物理整型合同均沿用。
16. Seed 1 在 14,000 步出现单次低档综合指标回退，16,000 步恢复改善。完成累计 20,000 步，以实际四档 Validation 选出该 checkpoint。对同一权重独立重放 E0 和 E1，保留 E1 优化前在 40 Mbps 的实际尾延迟失效。
17. 对两个真实 P 访问单元做同字节收端微基准。扩大原生熵编码批次，按完整段数调整 worker 数，逐位验证恢复整数。按相同 174 帧×3 口径重测，E1 在 40 Mbps 的 P95 从 33.60 ms 降至 30.47 ms。另构建带计时的收端确认记录内部的整数写入用时。

19. 将导入的模型 tag、三个 Full-max 重复、混合带宽状态和逐记录追加绑定到同一模型。用实测低档综合改善和这些工程结果决定 Seed 2 的正式训练准入。
