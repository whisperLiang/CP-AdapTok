# HLA-Tok V2 架构与控制

固定 K16320 用于连续表示和离散重建诊断。训练 Crop 按区域数缩放这一预算，保持 128×128 原生像素区域及 8×8 空间网格。模型共享 Spatial Encoder、双尺度融合、Local Token Decoder、Global RGB Decoder 和标准 8192×32 VQ。

| 模型 | 局部表示路径 | 局部容量 |
|---|---|---:|
| R0 | 原版两层独立 Cross-Attention | 512 |
| R1 | 两次 128→32 直接投影，按固定位置顺序输出 | 128 |
| R2 | 坐标位置编码和共享高斯偏置的两层 Cross-Attention | 512 |
| R3 | R2 的两层交叉注意力之间加入一层 Rank-Causal Self-Attention | 512 |

锚点按 $(x,y)$ 存储。首 16 个出自横纵都有 `0, 2, 5, 7` 的 4×4 子网格，先沿 x 再沿 y 顺序遍历。余下 48 项每轮取与已选集合最小平方欧氏距离最大的网格位置，距离并列采用最小行优先序号。固定 64 项的空间顺序按轮重复。前 64 个位置覆盖一次，前 128 个位置覆盖两次。R1 使用这一表的前 128 项。R2、R3 的偏置使用固定 σ 2.0、1.25、0.8，分别对应前 16 项、首轮余项与后续轮次。

R3 用 CrossBlock 1 产生的当前 32 Rank 输入投影 K/V。每个区域拥有自己的历史 K/V，当前行可访问绝对 Rank 小于或等于自身的键。训练保留跨 Chunk 的梯度，推理在帧范围内复用历史。R0、R2 及 R1 的顺序执行采用相同 32 Rank Chunk。R1 高于局部 128 项的请求由入口拒绝。

所有量化重建经 VQ ID 和查表进入共用 Decoder。原版 R0 的参数名、tensor 布局及旧检查点严格加载路径保留。新检查点存架构版本、固定表 SHA-256、Rank-Causal 配置及训练身份。缓冲表身份与加载前的公开确定性表进行核对。

R0-Scratch 与各候选从同一新初始化复制空间模块与解码模块。R2 与 R3 共享参数和锚点初值相同。R0-Continue 的独立入口从旧 VQ 轨迹恢复，供有界补训的历史控制使用。
