# HLA-Tok-HTS 工作记录

| 阶段 | 操作与依据 |
| --- | --- |
| 初始化 | 核验 V3 提交和单张 H100 PCIe。在 Codex 注册独立 worktree，并创建本地 `experiment/hla-tok-hts` 分支。 |
| 上游 | 将 DCVC 和 Original AdapTok 子模块检出至历史锁定提交。读取官方 RGB、I/P、参考、尾块、码流和训练实现。 |
| 权重 | 旧 API 返回 401 后使用 Microsoft 匿名公开分享流程。通过范围下载恢复 HT-S 慢速传输。四份文件核对官方 QuickXorHash、ZIP CRC 和本地 SHA256。 |
| TDD | 原生单元规划、校验和及重叠区间测试先观察到新增入口缺失，再建立实现并运行通过。 |
| 构建 | 复制官方源码到实验构建区，添加只读快照观察入口。重编变动的 C++ 目标并重用核验过的 CUDA 编译单元。 |
| H100 | 实跑 LD 和 HT-S 低码率起点。对照上游测试脚本验证原生字节、RGB、参考、上下文、独立 I 和 1～7 帧尾块。 |
| 扫描 | 使用逐段原生流、有效帧账本和真正的感知指标。源 DISTS 特征在同一裁段的 QP 扫描中复用，状态快照在 CUDA 上转为正则布局后计算相同哈希。 |
| 回归 | 为旧配置测试在新 worktree 中提供相同内容的预训练权重路径。为新增测试使用唯一模块名。保留重跑前日志和退出码。 |
| 对照 | 复用实际窗口包和队列，在同一批 128 帧回放 Original AdapTok、V2 Seed 2 + E1 和 V3 A4。额外测量 HT-S 原生未量化 y 的质量余量。 |
| 字节守恒 | 复解析落盘的 SPS/IP 文件，逐单元核对边界、QP、重置标志和有效帧范围。 |
| 图件 | 使用实测率失真前沿与真实单位峰值。将 I/P 图例移至数据区外，复查 PDF 字体和碰撞。 |
| CUDA 回归 | 覆盖率跟踪改用目录定位，以避开扩展模块重复导入。变异检查依据当次实际用例计数。原有 CUDA 回归 84 项及原生补充校验 2 项通过，8 个定向变异全部检出。 |
| 结案 | 408 个配置点完成，1,632 条原生流通过字节和 SHA256 复核。低码率准入 FAIL。资产清单复验通过，验证和测试像素读取均为 0。 |
