# AIP-VTok C1-Followup 实验报告

源提交 `a0f5eb8`，授权的实验分支 `experiment/aip-vtok-c1-followup`。

## Train-only 校准

Train 校准包含 13 个连续片段、34 帧。按图像 SHA256 排除原 C1 拟合窗口和两个完整训练计划用过的帧，并跳过 Gate 0 校准视频。A2/A3 保持 A0/A1 的 24 个通道。Top-36/48 在这 24 个通道后按新 Train 梯度敏感度补足。

原缩放为绝对值第 99.5 百分位除以 1.5。搜索覆盖尺度倍率、固定 μ-law 和逐组 levels 分配。每个 6D 符号保留 64,000 个可用 ID，并使用 16 bit 定长字。先按 Train 敏感度加权潜在误差筛选，再按 Train RGB MSE 选择每种 I/P 参数。A3 共用 A2 的一级量化器，二级输入是减去一级整数解码值的残差。

锁定候选为 **A2、A3**，锁定时间 2026-11-19T19:11:28+08:00。64-bit 槽位要求相对 A1 至少 +0.3 dB，128-bit 槽位要求至少 +0.5 dB。两档均容许 LPIPS、DISTS 各最多增加 0.005。128-bit 排序使用绝对质量对应的相对 A1 差值，即 ΔPSNR − 10×ΔLPIPS − 10×ΔDISTS − 0.05×log₂(总编解码时长/A1)。Validation 只能否决冻结入选项。[搜索记录和分组参数](../results/aip_vtok/c1_followup/calibration.json) · [候选锁](../results/aip_vtok/c1_followup/candidates.json)

## Phase 2 / 3 · 受控稠密训练

训练复用 C1-A 的原始 4 帧 detached-reference 因果展开、损失权重、AdamW、裁剪种子与逐步取样顺序。接收端模型输入来自整数 ID 解码。骨干与投影器冻结，训练逐帧检查发送、接收参考状态同步。

500 步要求同历史 ≥+0.2 dB、独立闭环 ≥0 dB，两种历史的 LPIPS 均改善且 DISTS 增量各 ≤+0.005。1,000 步要求两种历史各 ≥+0.5 dB，并继续满足感知指标、逐帧同步和保护审计。两个种子通过各自的 1,000 步终验后才放行稀疏端。
