# Quantization and teacher training

`configs/diagnostic_continuous.yaml` is a training diagnostic. It uses the same learned query encoder, project-in/out and unified decoder, but emits no token IDs. It cannot be encoded as an actual packet stream. Checkpoints from continuous warmup retain that restriction until discrete training begins.

`training.vq.strategy` accepts `continuous`, `deterministic_nearest`, or `stochastic_training`. Stochastic training samples the softmax of normalized cosine similarity divided by `temperature`; this matches the upstream AdapTok sampling distribution. Inference always uses the original squared-distance nearest neighbor. `sampling_topk: 0` means the full codebook; nonzero values explicitly restrict the distribution and are an approximation, not the upstream sampler.

`temperature`, `final_temperature`, and `anneal_steps` define a geometric schedule in absolute optimizer steps. `warmup_steps` uses continuous embeddings before switching strategies. `initialization: {clips: 8, max_samples: 32768, iterations: 10}` collects real training features and initializes the existing codebook at that boundary. Too few distinct samples cause an error. `dead_codes: {window: 20, max_replacements: 16, min_count: 1}` is optional and disabled by default. Recovery waits for a full update window and clears only recovered Adam moment rows. Checkpoints save the window, optimizer and CPU/CUDA/Python/sampling RNG states.

The default `teacher.policy: i_only` applies exact native decoded-latent MSE only to intra frames. P frames optimize reconstruction in CP's own base-prefix causal loop. `none` disables latent supervision. `legacy_ip` requires `allow_mismatched_p_diagnostic: true`; use it only for the T1 ablation. A same-context P target has not been verified and is rejected. `decay_steps` and `minimum_factor` reduce the latent weight during closed-loop fine-tuning.

Training diagnostics save the actual sampled and deterministic distributions separately, including all code counts. `diagnostic_steps` are **completed updates before the sampled forward**; a train row's `step` denotes the update just completed. Diagnostic reconstruction reports do not contain actual bitstream rates. Formal rates come from `cli.eval` with rANS packets and application record lengths.

`training.crop` accepts a square side, `[height, width]`, or `null` for the original input. Rectangular crops preserve pixels and do not resize. `resolution_schedule` selects the crop by absolute step. `sequence_schedule` similarly increases the number of causal frames, and `tbptt` bounds backpropagation. `fixed_sample_seed` is for overfit diagnostics and allows a fixed clip to be kept in memory during that run.
