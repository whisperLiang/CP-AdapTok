# Diag-0 工作记录

2026-11-19，Asia/Shanghai。

- 核对基线提交、原生 DMC-LD / DMCI 实现、Gate 0 对齐与投影、Fix-A 第 1000 步权重、六帧清单和原生 SPS/IP 码流。核实 H100 GPU 0 没有其他计算进程，并使用原生运行环境。
- 先新增验收测试并确认在 Diag-0 尚未实现时失败，再实现 I/P 流式协方差、冻结 Decoder 梯度、离散 FSQ 与固定参考提交。小规模原生冒烟测量了指标与反向输入梯度，检查 CUDA 严格确定性兼容性。
- 使用经过原文件帧哈希核验的 35 个训练视频各四帧拟合；两种帧型各取 12 帧测梯度，训练量化尺度和锚点残差尺度分别入档。读取边界允许 Validation 清单中的 historical-development 角色，并用测试验证 Train 入口拒绝该角色。
- 首轮 A–D 在一帧 Fix-A P 历史上发现单次 FP32 点积累加的往返误差略微超界。改成短点积与独立 FP32 求和，在完整 60 个上下文上先复核所有 180 组往返与 PSNR，再执行正式扫描。
- 使用 30 帧干净 R0 历史与原 Fix-A 同历史六帧比较 A–D，并在全部选定的低预算历史上另跑 A。读入每个关键帧前推进同一来源的上下文，编码器和 Decoder 上下文对所有同帧候选保持固定。
- 在隔离的临时副本内做六个行为变异，覆盖均值恢复、验证集越界、空间块成本、组前缀、整数载荷和参考提交，六个变异全部触发测试失败。命名 crapper/dryer/mutator 工具在当前环境不可用，使用仓库已有的 Radon、实际覆盖率、AST 重复检测和隔离变异脚本口径。
- 使用 Matplotlib 生成各诊断对应的定量图，对深度布局的图统一面板宽高和物理间距。原生裁剪使用相同固定坐标，保留每个像素，方便逐布局比较。
- A–D 正式测量完成后，根据配对验证的四项质量指标进行候选排序。顺序执行封存 Fix-A、全分辨率连续组前缀和 Hybrid，各跑原生 GOP32 的 64 帧。两种显示预算的 192 次参考提交逐位相同，Fix-A K8192 的 RGB MSE 与两项潜在 RMS 逐帧精确复现。
- 隔离执行联合回归，确认 235 项原有用例与 16 项 Diag-0 用例全通过。重复训练统计，38 个拟合张量逐位相同。抽查四个同历史验证上下文，482 条 A–D 结果逐字段相同。
- 验证五组 JSON 和 CSV 的逐帧数量、FSQ 分组计数和深度字节公式。核对 645 个原有实验文件、冻结 Projector 的哈希与保护代码路径。图表通过面板对齐、PDF 字号和碰撞检查，并逐图检查原生裁剪和坐标。
- 合并单元测试、闭环、报告和确定性复测的覆盖记录，最大 CRAP 为 9，AST 相似度达到 0.8 的函数对为 0。产出情景 C 决策、原始表格、图表和验证记录，将诊断实现与实验交付分别提交到 experiment/aip-vtok。
