# A Pilot evidence snapshot

Both seeds and all four 300-update D3 continuations are complete. These are actual native 1080p packet measurements, with matched exposure and measured standalone timings. No unified arm passed the two-seed LPIPS/adoption gate; the lowest-LPIPS unified candidate is used only for the from-scratch study.

The manifest binds every copied file to its original result path and SHA256. Per-frame quality, packet hashes, checkpoint metadata and native P31 samples are included. Complete .pt optimizer states and .bin packet files remain in the independent local roots and will be included as applicable in the final raw-evidence package. B is still in progress; this is not a from-scratch conclusion.
